# 🚗 BiDrive — платформа онлайн-аукционов автомобилей

**BiDrive** — веб-приложение для проведения онлайн-аукционов автомобилей: прозрачные торги в реальном времени, модерация лотов, многокритериальный поиск и оперативное информирование участников через Telegram.

## ✨ Возможности

### Гость
- просмотр каталога автомобилей;
- многокритериальная фильтрация: марка, модель, год, цена, пробег, топливо, КПП, регион;
- карточки лотов с фотографиями и историей торгов;
- регистрация и вход в систему.

### Пользователь
- участие в торгах и ставки в реальном времени;
- создание собственных лотов с загрузкой фотографий;
- личный кабинет: профиль, история ставок, уведомления;
- уведомление о перебитии ставки;
- подписка на новые лоты через Telegram.

### Администратор
- модерация лотов (одобрение / отклонение с причиной);
- управление пользователями (блокировка / разблокировка);
- ведение справочников: марки, модели, города, области;
- статистика платформы: пользователи, активные аукционы, ставки, топ марок.

## 🛠 Технологический стек

### Backend
- **Java 25 + Spring Boot 4** — серверная часть и REST API
- **Spring Security** — аутентификация, авторизация, хэширование паролей (BCrypt)
- **Spring Data JPA + Hibernate ORM** — работа с базой данных
- **Telegram Bot API** — уведомления о новых лотах
- **API НБ РБ** — актуальный курс USD с кэшированием
- **Maven, Lombok**

### Frontend
- **React 19 + Vite** — клиентская часть
- **React Router DOM, Axios**
- **CSS Modules, Flexbox**
- светлая и тёмная темы, адаптивность от 320 px

### Хранилище данных
- **PostgreSQL 18** — 13 нормализованных таблиц
- **pgAdmin** — администрирование БД

## 🔐 Безопасность

Проект реализует комплексный подход к защите данных:

- **HTTPS на этапе разработки** — фронтенд работает по протоколу `https://localhost:5173` с использованием self-signed сертификата, сгенерированного через OpenSSL. Это позволяет тестировать работу браузера в режиме защищённого соединения (Secure Context) и корректную работу Web API, требующих HTTPS.
- **Хэширование паролей** — пароли пользователей хранятся в БД в виде BCrypt-хэшей, что делает невозможным их восстановление в случае утечки.
- **JWT-аутентификация** — Spring Security управляет сессиями и токенами доступа.
- **Разделение секретов** — чувствительные данные (токены Telegram, пароли БД) вынесены в переменные окружения и не попадают в Git-репозиторий.
- **Валидация форм** — проверка данных на стороне клиента и сервера.
- **Защита от XSS и CSRF** — реализованы через настройки Spring Security.

> ⚠️ **Примечание:** при первом запуске браузер может показать предупреждение «Ваше подключение не защищено». Это нормально для self-signed сертификата. Нажмите «Дополнительно» → «Перейти на localhost (небезопасно)».

## 🗄 Структура базы данных

| Таблица | Назначение |
|---|---|
| `users` | пользователи: контакты, хэш пароля, статус блокировки |

## 🚀 Запуск локально

### Требования
- JDK 25
- Node.js (LTS)
- PostgreSQL 18
- Git
- OpenSSL (для генерации self-signed сертификата)

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/MaSarelo/BiDrive.git
cd BiDrive
```

### 2. Настройте базу данных
Создайте БД `bidrive` в PostgreSQL:
```sql
CREATE DATABASE bidrive;
CREATE USER bidrive_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE bidrive TO bidrive_user;
```

### 3. Настройте переменные окружения
В корне проекта создайте файл `.env` (или настройте их в IDE):

```env
# Backend
DB_PASSWORD=your_password
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

> 🔒 **Важно:** файл `.env` уже добавлен в `.gitignore` и не попадёт в репозиторий.

### 4. Запустите Backend
```bash
cd backend
./mvnw spring-boot:run
```
> 💻 **Windows:** используйте `mvnw.cmd spring-boot:run` вместо `./mvnw spring-boot:run`.

Backend будет доступен на `http://localhost:8080`.

### 5. Запустите Frontend
```bash
cd ../frontend
npm install
npm run dev
```
Frontend будет доступен на `https://localhost:5173`.
